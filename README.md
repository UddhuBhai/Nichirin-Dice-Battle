# ⚔ Nichirin Dice Duel

An anime-inspired **2-Player Dice Battle Game** built using **HTML**, **CSS**, and **JavaScript**. Choose your favorite **Demon Slayer** characters, roll the Nichirin dice, and let fate decide who emerges victorious.

## 📖 About

**Nichirin Dice Duel** reimagines the classic dice game with a **Demon Slayer** theme. Two players select their slayers, enter the battle arena, and roll animated dice to determine the winner.

Designed to be both entertaining and visually immersive, the project combines interactive gameplay with modern UI animations and anime-inspired styling.

## 🚀 Features

* ⚔ Two-player character selection
* 👹 Choose from multiple Demon Slayer characters
* 🎲 Animated dice rolling
* 🏆 Automatic winner detection
* ✨ Winner highlight animation
* 🔄 Play Again functionality
* 📱 Responsive design
